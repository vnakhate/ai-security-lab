The lab controls how tools connect.

A reviewer checks the evidence from each test. The evidence must support the result for the specified OWASP category.

Technical terms
  • Scope: The approved targets, routes, methods, and limits for a test.
  • Campaign: A planned group of tests.
  • Adapter: Code that converts lab instructions into tool or target requests.
  • Runner: The isolated environment that executes tools. VM means virtual machine.
  • Relay: A service that forwards model requests and enforces their limits.
  • Evidence: Requests, responses, logs, files, and observed effects that support a test result.
  • Coverage: The OWASP test objectives that reviewed evidence supports.
Risk groups

The target determines which OWASP list applies.

Assignments

Each tool needs an adapter and an approved test case.

Model roles

The assistant model and the target model have different roles.

Requirements for models and agents
  • Check planning, tool use, and review separately against known results.
  • A local-only campaign prevents model calls to external services. It also prevents automatic use of a cloud model.
  • Approve the data before an external model call. Specify the provider contract. The operator proposed Grok 3.7 Cyber. Its endpoint remains unconfirmed.
  • Check the license before using a model with open weights. Open weights do not prove that all model components are open source.
  • Agents use predefined action types. The relay limits model requests. Keep provider keys on the host.
