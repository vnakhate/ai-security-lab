Check price, power, and model capacity.

ASUS listed the reference RTX 5090 card at $4,399.99 during research. NVIDIA specifies 575 W of reference graphics power.

A dense 32B model uses approximately 16 GB for raw four-bit weights. Runtime data and context require additional memory.

A dense 70B model needs more than 32 GB for raw four-bit weights. This plan does not target that configuration.

Check actual UPS load. Check shutdown operation. A wattage rating does not establish battery runtime. Check cooling and GPU clearance before purchase.

Network

The firewall checks traffic between segments.

The switch carries virtual local area networks (VLANs). Disable routing between VLANs on the switch. Check address overlap before installation.

InferenceGPU machine and inference APISeparate management and inference interfaces. Disable forwarding on the host.

QuarantineNew images and downloaded toolsPermit approved downloads during a recorded installation window.
Set host and switch boundaries.
  1. Use the firewall address ending in .1 for each subnet.
  2. Assign fixed addresses to infrastructure.
  3. Assign separate address pools to disposable workloads.
  4. Restrict the test-host trunk to management, agents, and targets.
  5. Do not expose a VLAN trunk to a guest VM.
  6. Keep hypervisor administration in the management segment.
  7. Disable forwarding on the evidence and inference machines.
  8. Apply host rules to traffic within each segment.

These ports describe proposed services. The current lab does not deploy the broker or evidence-ingestion service.

Connect the current harness without removing its scope checks.

The current harness accepts numeric loopback endpoints only. A dedicated inference machine needs a reviewed gateway or an authenticated network adapter.

Keep the loopback restriction until that integration passes scope tests. A gateway must enforce its outbound destinations independently.

The target model path needs separate authorization. A local API address alone does not prevent a runtime from using hosted models.

Build sequence

Check each boundary before agent execution.

Acceptance checkRequired evidence
Network isolationApproved paths succeed. Agents and targets cannot reach ordinary LAN devices or administration endpoints.
Evidence protectionA test identity can submit records. It cannot read, replace, or delete retained records.
Reset and recoveryA fresh target starts from known state. A restore produces the expected state.
Power and coolingMeasured load fits the UPS. Shutdown succeeds. Sustained inference stays within component limits.
Model behaviorTasks produce usable output. Reports preserve failures, incomplete cases, and variation between runs.
Human acceptanceA reviewer checks underlying evidence. A manual baseline supports any claim of AI value.

Agent and target VMs share one physical hypervisor in this proposal. Use a separate physical target for kernel attacks or VM-escape research.
